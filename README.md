# 莓好學習區 PWA

不需要登入或後端的靜態學習 APP，可部署到 GitHub Pages。

## 目前功能

- 教材中心：先分英語、數學兩個科目。
- 英語：進入後分國小區、國中區；國小區有 73 個學習日（每天 5 個新字，每字只學一次）；學完做 10 題小考，全對才亮燈並解鎖下一天；每 6 天為一週，第 6 天週考（共 15 次，全對才通過）；小考、週考要全對；儀表板的「📝 進度抽考（複習）」依已學的字抽 10 題（曾答錯的優先），滿分 100、80 分以上通過，是學過的字唯一重複出現的地方（獨立檢驗，不影響亮燈，記錄最高分）。排程與出題邏輯在 `dist/english-plan.js`，可用 `node dist/verify-english.js` 檢查。
- 英語國中區：七、八、九年級各自的每日單字、片語句型、例句閱讀、複習測驗模組骨架。
- 數學：目前為國小六年級，依翰林、康軒、南一三種版本分流；各版本涵蓋六上、六下全年單元、小節卷與總評量。
- 版本架構：`dist/course-catalog.js` 集中管理版本名稱、狀態、說明與入口，後續新增版本不必重寫首頁。
- PWA：可安裝、Service Worker 離線快取。
- 本機進度：localStorage 儲存（英語進度 schemaVersion 2，舊版進度會備份後重新開始），支援 JSON 匯出／匯入。

## 目錄

- `dist/`：可直接發布的網站。
- `.github/workflows/deploy-pages.yml`：GitHub Pages 發布流程。
- `協作/`：工作日誌、交接與除錯紀錄。

## 本機預覽

在 `dist` 啟動任一靜態 HTTP 伺服器後，以瀏覽器開啟網址。Service Worker 不支援直接用 `file://` 開啟。

## 資料限制

國小詞庫目前有 365 個不重複核心單字。前 15 字含 IPA 與台灣兒童發音提示；其餘單字以瀏覽器的美式語音播放為準，避免顯示未校對的假音標。國中區目前只有可擴充架構，尚未填入未經使用者提供或審核的教材。
