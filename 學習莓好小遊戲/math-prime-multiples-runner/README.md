# 3D 數學跑酷｜質數與倍數大挑戰

狀態：規格盤點中，尚未整合、尚未驗收、尚未部署。

## 原始依據

- 使用者提供的獨立 HTML 原型：`3D數學跑酷冒險：質數與倍數大挑戰(1).html`
- 使用者提供的場景背景：`草莓夢境質數闖關樂園.png`
- 使用者提供的主選單 UI：`草莓數學跑酷挑戰介面.png`
- 使用者提供的角色素材：`草莓帽萌兔奔跑姿勢.png`、`藍莓飛躍搗蛋貓.png`

實際素材檔案尚未提交到此資料夾。正式實作時必須使用這些原始附件，不得用搜尋示意圖或重新生成圖片替換。

## 功能範圍

- 學習模式：質數 vs 易錯合數、13 的倍數、19 的倍數、綜合大魔王考驗。
- 角色：草莓帽萌兔、藍莓飛躍搗蛋貓。
- 場景：沿用提供的莓果夢境視覺。
- 遊戲資訊：關卡、得分、進度、目前任務與答題回饋。
- 控制：音效、暫停、回到遊戲入口／教材中心。
- 輸入：支援原型既有的鍵盤與觸控方式；滑動與跳躍需實測。

## 必驗規則

1. 題庫中每個數字與正確答案須有可追溯的判定依據。
2. 「完整題庫一輪大考驗」必須確實要求題庫內所有目標數字連續答對才通關。
3. 答錯後連勝、題目佇列與關卡狀態必須一致重置，不能混入上一輪舊題。
4. 綜合模式必須在一輪中真正混合不同題型，不能只在啟動時抽中一種題型。
5. 13 與 19 的倍數題目須包含足夠的正例、反例，並確認顯示數字與判定相符。
6. 暫停、重開、音效開關、角色選擇、返回入口不得卡住遊戲狀態。
7. 遊戲不能遮擋或破壞學習中心原有頁面功能。
