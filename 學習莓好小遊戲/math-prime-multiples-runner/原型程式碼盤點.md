# 首款遊戲原型程式碼盤點

盤點依據：`source/original/3D數學跑酷冒險：質數與倍數大挑戰(1).html`
盤點方式：靜態讀取原始 HTML；尚未在瀏覽器執行，因此以下區分「程式碼可確認」與「仍需動態驗收」。

## 已確認的結構

- 單一 HTML 內包含介面、題庫、Three.js 場景、控制、關卡與音效程式。
- 使用 Three.js r128、Tailwind CDN、Tone.js 14.8.49。
- 題型模式：質數／易錯合數、13 的倍數、19 的倍數、綜合模式。
- 控制包含方向鍵／WASD、空白鍵跳躍、觸控滑動、暫停快捷鍵。
- 遊戲角色目前由 Three.js 幾何形狀程式建立；尚未載入使用者提供的兩張角色 PNG。
- 3D 場景背景以程式設定粉色底色與霧效；尚未載入使用者提供的莓果夢境背景圖。
- HTML 使用 CDN；離線可用性尚未建立或驗證。

## 靜態檢查發現

### BUG-01｜綜合模式並未在同一輪混合題型
位置：`buildFullQuestionPool()`
目前在 `gameMode === 'mixed'` 時，只從 `prime`、`mult13`、`mult19` 隨機抽出一個 `targetType`，整輪題庫都只生成該類題型。
影響：與「綜合大魔王考驗」應混合不同題型的預期不一致。
修正方向：以各子題型建立題目集合後合併、打亂；確保每輪包含各題型，並明確設定通關題數。

### BUG-02｜答錯後已生成的舊關卡仍留在場景
位置：`checkGateCollision()` 的答錯分支
答錯後會重建 `questionSequence`，但只呼叫 `buildFullQuestionPool()`，沒有清除場景中其他已生成的 `gates`。這些舊閘門仍保存舊題目，可能與新題庫佇列不同步。
影響：重新開始整輪時，畫面上仍可能出現舊輪次題目，進度計數與實際題目順序可能不一致。
修正方向：將錯答重置抽成單一函式，統一重建題庫、清除舊閘門、重設連勝與進度，再依目前跑道狀態重新生成。

### BUG-03｜音效初始化可能重複建立資源
位置：`startGame()`、`initAudio()`
`startGame()` 每次執行都呼叫 `initAudio()`，而 `initAudio()` 建立新的 Synth 與 Loop。返回選單後再次開始遊戲可能重複建立音訊節點或循環。
影響：可能造成音效重疊、資源未釋放或重複背景音樂。
修正方向：音訊初始化採單次建立；開始／暫停／返回選單只控制既有 Transport 與 Loop 狀態。

### BUG-04｜多次開始或重新開始後的場景資源生命週期需驗證
位置：`resetTrack()`、`createFireworkCluster()`、`updateFireworks()`
目前移除閘門與煙火 Mesh 時，尚未看到對幾何體與材質的 dispose 管理。
影響：長時間或反覆遊玩可能累積 GPU 資源。
修正方向：在工程化時集中管理 Mesh 與資源釋放；需以瀏覽器效能監測確認。

### BUG-05｜外部 CDN 與 PWA 離線行為未處理
位置：HTML head 的 Tailwind、Three.js、Tone.js 外部 script。
影響：CDN 載入失敗或離線時，遊戲核心可能無法啟動。
修正方向：先確認專案現有套件與建置工具；採用既有依賴策略，避免盲目引入第二套建置流程。離線策略需與學習中心 Service Worker 一併驗收。

## 仍待動態驗收

- 題庫所有答案與解釋是否完全一致。
- 13、19 倍數模式所有干擾選項是否符合預期。
- 遊戲碰撞與跑道速度在不同畫面尺寸的表現。
- 暫停／繼續、返回選單、重玩後音訊與動畫狀態。
- 手機觸控、鍵盤操作與瀏覽器 Console 錯誤。
- 關卡通關題數、得分、連勝、進度顯示是否一致。
- 角色選擇是否真正影響玩家模型（需檢查原型完整流程）。
