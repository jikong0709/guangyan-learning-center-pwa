# 學習莓好小遊戲

本資料夾是「莓好學習中心」內所有學習小遊戲的集中開發區。每款遊戲先在本資料夾內獨立開發、測試與驗收，再透過學習中心既有頁面／課程入口接線；不得直接改動或取代學習中心首頁。

## 開發原則

1. 所有遊戲只在 `feat/meihao-learning-games` 分支開發；禁止直接推送 `main`。
2. 每款遊戲使用獨立子資料夾，避免遊戲程式、素材與狀態互相污染。
3. 優先沿用學習中心既有架構；接線前先讀取入口與路由實作，不猜測檔案位置。
4. 只有在完成測試並獲得授權後，才可透過 PR 整合；未經授權不得合併或部署。
5. 不得刪除或覆蓋現有科目、教材、題庫、素材或資料。
6. 不得把未實測的功能標記為完成。
7. 不得自行生成或替換使用者指定的品牌素材；使用已提供的原始素材。
8. 外部 CDN、音訊、PWA 快取及離線支援都必須列入測試，不得假設可用。

## 遊戲目錄規劃

```text
學習莓好小遊戲/
├── README.md

└── math-prime-multiples-runner/    # 首款：3D 數學跑酷
    ├── README.md                   # 遊戲規格、操作、測試與進度
    ├── src/                        # 遊戲程式
    ├── assets/
    │   ├── backgrounds/             # 使用者提供的背景
    │   ├── characters/              # 草莓帽萌兔、藍莓飛躍搗蛋貓
    │   └── ui/                      # 使用者提供的主選單及 HUD 美術
    └── tests/                       # 題庫、關卡、重置及操作測試
```

實際建置時應先檢查專案現有工具鏈與檔案慣例，再決定是否採用上述子目錄；不可為了套用此規劃而重建整個網站。

## 整合回學習中心的規則

- 遊戲完成前先在本分支獨立驗收。
- 接線前檢查首頁入口、課程目錄、路由、資源路徑、建置輸出目錄及 Service Worker。
- 優先新增獨立入口，不改寫既有科目邏輯。
- 變更 Service Worker 快取時，確認版本更新策略，避免新舊資源混用。
- 驗收至少涵蓋桌機、手機、鍵盤／觸控、題庫正確性、答錯重置、分數與通關、音效、資源載入及既有科目回歸測試。
- PR 應列出檔案變更、測試結果、已知限制及是否涉及部署；只有獲得明確授權後才可合併或部署。
