## 3. 題型與模板（與數學一致，但只有四種）
題型 key：`single` 單選、`multi` 複選、`tf` 是非、`fill` 填空。**沒有** `calc`、`word`（這三科不要）。
資料契約沿用規格第 2 節：每個 spec 有 `id`（全域唯一、格式 `<topic>-<type>-L<級>-NN`）、`type`、`level`(1~5)、`tag`(`basic`/`trap`/`extend`)、`gen(kit)` 回傳 `{stem, options?, answer, accepted?, explain, trapNote?}`。
- 這三科答案是固定事實，**只要一種解析（`explain`），不要 `explain2`**（引擎沒有 `explain2` 時只顯示一種解析，不報錯）。
- 「動態變數」在這三科的意思是：同一個知識點用多個說法／干擾項組合出題、選項順序由引擎洗牌、從候選事實池隨機抽取（用 `kit.pick`／`kit.shuffle`），讓每次出的題不完全相同；不是數字運算。
- 單選 4 個選項、干擾項要看起來合理且對應常見誤解；複選 4～5 個選項、至少 2 個正解、至少 1 個錯項、題幹明示「選出所有正確的（複選）」；是非題幹為單一陳述句；填空題 `answer` 為標準答案字串，`accepted` 放等價寫法（同義詞、繁簡不用、全形半形），填空題幹用「（　）」或「□」標空格；`explain` 為一句到三句的完整解析，說明為什麼；`trapNote`（`tag: "trap"` 必填）說明學生常錯在哪。
- 國語閱讀測驗：在 `stem` 裡放一小段短文（80～200 字，**自編原創短文**，不得抄課文或他人文章），再問問題；同一段短文可配 2～3 題（各自獨立 spec，短文用同一個函式／常數）。
- 每個 topic 的量化門檻（比數學高，因為沒有數字變化）：`single` ≥ 12、`multi` ≥ 6、`tf` ≥ 12、`fill` ≥ 10；level 1～5 都要有（每型涵蓋 ≥3 級）；`trap` ≥ 10（分布於 ≥3 種題型）、`extend` ≥ 8（跨單元、推論、比較、應用情境）。同一 topic 內不得有兩個 spec 考同一個事實。
- 繁體中文（台灣用語），禁簡體詞（视频→影片、获取→取得、点击→點擊、确认→確認等）。

## 4. 內容範圍與單元（**必須有可查證來源**）
年級：國小六年級（上、下學期）。版本：翰林、康軒、南一各自單元表（比照數學 config 的 `versions → units → topics`）。
- 單元清單請依公開來源查證（出版社官網課程介紹、教育部審定教科書資訊、均一教育平台等；你有網路）。**查證得到的單元才寫進 config**；查不到的版本／單元，標 `verified:false` 並在註解與回報中說明，單元名稱用課綱主題名稱代替，不得捏造出版社單元名。
- `topics` 以「知識主題」為單位，三版本共用題庫（跟數學一樣：單元對應到 1～3 個 topic）。每科 topic 數量建議 10～14 個，涵蓋六上、六下。
- 國語 topic 例（可依查證結果調整）：字音字形、字詞辨析（形近／音近）、詞語運用與成語、標點符號與修辭、句型與語法（照樣造句改寫判斷題）、文意理解（閱讀測驗：記敘）、文意理解（閱讀測驗：說明／議論）、文學常識與文化常識、閱讀策略與推論、語文表達（書信、公告、摘要）。
- 社會 topic 例：地理（台灣與世界）、歷史（台灣史、世界史）、公民（權利義務、民主、經濟）等六年級課綱主題，按查證到的單元對應。
- 自然 topic 例：物質與能量（光、聲音、電、熱）、地球與宇宙、生物與環境、科學方法與實驗設計、永續與環境等六年級課綱主題。自然的實驗圖表題一律用文字敘述數據。
- 若某 topic 的內容會因版本而不同（例：某版本沒教），在 config 的單元對照裡只把該 topic 對應到有教的版本。
